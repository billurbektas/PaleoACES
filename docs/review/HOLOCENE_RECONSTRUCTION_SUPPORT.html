Reconstruction

Original macrofossil samples are identified by core depth (MORA) or Neotoma sample ID (NOCA). Taxonomic categories are harmonized within each original sample; samples sharing a median age remain separate. The fixed 607-plot, 14-taxon CCA projects sample WA positions before averaging. The audit uses 1,000 complete chronology rows per core from the existing stored Bacon posteriors, without MCMC or sampling with replacement. Bacon evaluates temporary core copies; the source posteriors and configurations are unchanged.

Samples are assigned to each lake’s native CHELSA intervals [lower, upper). Centroids average sample WA positions within each draw and century. Reconstructed coordinates are medians of the centroids across occupied draws. Occupancy is the number of draws containing at least one eligible sample, divided by 1,000. Empty centuries have zero occupancy and undefined coordinates. Coordinate quantiles are conditional on occupied draws, not model confidence intervals.

The calculation excerpt below is taken directly from the maintained helper:

  centroids = assignments |> dplyr::filter(!is.na(century_cal_bp)) |>
    dplyr::group_by(site, lake, draw, century_cal_bp) |>
    dplyr::summarise(observed_CCA1 = mean(observed_CCA1), observed_CCA2 = mean(observed_CCA2),
      n_samples = dplyr::n(), .groups = 'drop')
  positions = centroids |> dplyr::group_by(site, lake, century_cal_bp) |>
    # Quantiles precede names that replace source coordinates in summarise().
    dplyr::summarise(CCA1_q025 = quantile(observed_CCA1, .025, names = FALSE),
      CCA1_q975 = quantile(observed_CCA1, .975, names = FALSE),
      CCA2_q025 = quantile(observed_CCA2, .025, names = FALSE),
      CCA2_q975 = quantile(observed_CCA2, .975, names = FALSE),
      observed_CCA1 = median(observed_CCA1), observed_CCA2 = median(observed_CCA2),
      n_occupied_draws = dplyr::n_distinct(draw), n_draws_nmin2 = sum(n_samples >= 2),
      n_samples_median = median(n_samples), .groups = 'drop')

These scenarios do not select a cutoff. Each scenario reconstructs its own endpoint pairs; a transition joining two retained centuries can span unoccupied centuries or occupied centuries skipped by that scenario. Those two causes are counted separately. Empty scenarios contain zero counts and unavailable distribution statistics.

A stronger occupancy cutoff can also create long bridges by excluding occupied intermediate centuries. Inspect duration_max alongside the support distributions before choosing a rule; no maximum-gap exclusion is imposed here.

Fire coverage

Fire activity counts accepted events over the entire [age_lo, age_hi) transition. A fully covered core contributes event_count * 100 / duration_years events per century. MORA requires at least two fully covered regional cores and averages them equally; NOCA requires Panther Potholes coverage. The unit is events per century per eligible core. Covered zero-event windows are zero; missing coverage is NA. The three MORA vegetation lakes share the regional charcoal history. Counts of distinct shared exposures are exported separately. This audit does not change the normalized 1,000-year fire predictor or CC/S descriptive classification.
