## Output files

All cleaned and standardized outputs are saved in `CLIMreassembly/MORAcleaning/outputs/`. They are ready for downstream statistical analysis and ecological interpretation.

---

### `MORA_plots.rda`
RData file with two objects:

#### 1. `plot_lib`
Plot ID equivalency table.
| Column   | Description                                                   |
|----------|---------------------------------------------------------------|
| Plotno   | Legacy plot number format                                     |
| plot_id  | Cleaned and standardized plot ID (used in all other datasets) |
| Plot_ID  | Resurvey plot ID format                                       |

#### 2. `plot_info`
Cleaned ecological metadata.
| Column    | Description                              |
|-----------|------------------------------------------|
| plot_id   | Unique standardized plot ID              |
| latitude  | Latitude (decimal degrees)               |
| longitude | Longitude (decimal degrees)              |
| elevation | Elevation in meters                      |
| aspect    | Aspect (degrees from north)              |
| slope     | Slope steepness (degrees)                |

---

### `MORA_species.rda`
RData file with two objects:

#### 1. `spp_lib`
Detailed species reference.
| Column        | Description                                                       |
|---------------|-------------------------------------------------------------------|
| prst_code     | Present species code (2023 format)                                |
| prst_name     | Original name used in resurvey datasets                          |
| final_species | Standardized scientific name from TNRS                           |
| final_family  | Family name                                                      |
| past_code     | Legacy species code                                              |
| past_name     | Legacy species name                                              |
| canopy_type   | Assigned canopy group (see note below)                           |

#### 2. `spp_list`
Simplified one-row-per-species table.
| Column    | Description                     |
|-----------|---------------------------------|
| prst_code | Standardized species code       |
| species   | Final scientific species name   |
| family    | Family name                     |
| canopy_type | See description in `spp_lib` |

**Note on `canopy_type` classification:**  
Assigned in `clean_species_names.R` based on DBH data:
- `overstory_full`: all species with DBH measurements  
- `overstory_rare`: subset of overstory_full with very low total occurrences (~3)  
- `overstory`: main overstory species with consistent presence and DBH  
- `understory`: species with no DBH data, assigned to understory

### `MORA_overstory.rda`
RData file with five objects:

#### 1. `over_long`
Long-format dataset for overstory trees.
| Column              | Description                              |
|---------------------|------------------------------------------|
| period              | `past` or `present`                      |
| year                | 1975 or averaged 2015                    |
| plot_id             | Cleaned plot ID                          |
| plot_area           | Plot area in m2                          |
| species             | Scientific name                          |
| occurrence          | Binary presence (0/1)                    |
| count               | Number of individuals                    |
| basal_area_spp_m2   | Total basal area in m2                   |
| basal_area_spp_percent | Relative cover (%)                    |
| density             | Individuals per m2                       |

- **Number of observations**: 2,403 rows  
- **Number of unique plots per period**: 331  
- **Number of species**: 12

#### 2. `over_matrix_occ`
Wide-format occurrence matrix (presence-absence). 
- Rows: 662 (331 plots × 2 periods)  
- Columns: `plot_id`, `period`, `year`, `plot_area`, + 12 species

#### 3. `over_matrix_abun`
Wide-format abundance matrix (individual counts).
- Same dimensions as `over_matrix_occ`

#### 4. `over_matrix_cov`
Wide-format cover matrix (relative cover in %).
- Same dimensions as `over_matrix_occ`

#### 5. `over_ageclass_spp`
Individual abundance by diameter class and period.
| Column     | Description                     |
|------------|---------------------------------|
| plot_id    | Plot identifier                 |
| species    | Scientific species name         |
| class_size | Diameter class label            |
| num_ind    | Number of individuals           |
| year       | Year                            |
| period     | `past` or `present`             |

- **Total rows**: 19,988  
- **Number of unique DBH classes**: 140

---

### `MORA_understory.rda`
RData file with three objects:

#### 1. `under_long`
Long-format data for understory species.
| Column     | Description                            |
|------------|----------------------------------------|
| plot_id    | Cleaned plot ID                        |
| period     | `past` or `present`                    |
| year       | 1975 or 2015                           |
| species    | Scientific name                        |
| cover      | Relative cover estimate (%)            |
| occurrence | Presence based on cover (0/1)          |

#### 2. `under_matrix_occ`
Presence-absence matrix.
- Rows: 628 (314 plots × 2 periods)
- Columns: `plot_id`, `period`, `year`, + 208 species columns

#### 3. `under_matrix_cov`
Cover matrix (relative cover in %).
- Same structure as `under_matrix_occ`
